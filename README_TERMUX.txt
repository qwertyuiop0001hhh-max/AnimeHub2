ANIME HUB 2 — запуск в Termux

1. Установи Node.js:
   pkg update -y
   pkg install nodejs -y

2. Распакуй папку проекта и перейди в неё:
   cd AnimeHub2_Termux

3. Установи зависимости:
   npm install

4. Запусти:
   npm start

5. Открой в браузере:
   http://127.0.0.1:3000

РЕЖИМ РАЗРАБОТЧИКА
Кнопка находится внизу сайта. Открывается графическим ключом. Внутри можно выбрать аниме, сезон и серию, нажать «+ Видео», выбрать видео из галереи и загрузить его на сервер. После загрузки серия появляется у всех посетителей этого сервера.

ВАЖНО ДЛЯ ПУБЛИЧНОГО САЙТА
Локальный адрес 127.0.0.1 виден только на телефоне. Чтобы другие люди могли зайти, нужен публичный сервер/туннель или хостинг, где Node.js доступен из интернета. Папки uploads и data нельзя удалять — там находятся видео и список серий.

Постеры
Сайт автоматически получает реальные обложки из публичного API Jikan/MyAnimeList. Для их загрузки нужен интернет.
